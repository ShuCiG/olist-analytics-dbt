# Review texts to label (branch `data/review-labels` only)

Every Olist review with a title or message (42,389 reviews), exported by `labels.py export-queue` from the raw
`order_reviews` table, so that a scheduled cloud session can label them without the local dump. Source: Brazilian
E-Commerce Public Dataset by Olist (Kaggle), licence CC BY-NC-SA 4.0. Not merged into `main`: only the labels are.
